# Silhouette and composition correction

The first Ranger was too similar to Classic, and the three menu treatments mostly changed borders. This pass gives Ranger a separate procedural factory in client/rig-ranger.ts: a forward-control cab, broad raked windscreen, short wedge nose, enclosed pale utility body, angular arch eyebrows, low solar roof and a different cab camera anchor. Classic keeps its pickup silhouette. Four contact points, radius and track match the existing simulation. Ranger owns and disposes all materials/geometries, including unused materials in Light loadout. No campaign state is read.

Splash composition now differs by treatment. Glass has a large unboxed DRIVE action above sparse navigation. Instrument uses a framed bottom console with a 2x2 navigation block beside DRIVE. Docket has a numbered vertical list beside departure controls. Location is the headline; the tagline is in About and drive statistics are in a new Progress page. The existing camera band now measures the location header's bottom, preserving clear space beneath it. The main simulation otherwise remains unchanged.

Checks passed: TypeScript menu/rig modules, geometry construction and disposal across all six configurations, twelve integration swaps preserving position/paint/wheel pose, menu interaction/persistence checks. Geometry-only SVG projection confirms separate silhouettes but is not a substitute for the game's shaded rendering. Live in-game visual/FPS verification remains unavailable because the cloud browser cannot initialise WebGL; its local isolated-preview URL was also blocked. Please judge the deployed result on a WebGL-capable device. No performance improvement is claimed.
