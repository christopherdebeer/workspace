Return to the source.
Every name, identifier, number, date and place: as the source gives it, exactly, and none the source does not give.
Change the wording; return to the source.
Where a change would alter a meaningful detail the source does not support, keep the earlier wording.
Where the source is silent, write [unknown]. Do not invent.
Return to the source.
