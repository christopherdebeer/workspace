# Reference Set — Index

The parc.land substrate reference is one overview (`platform-core.md`), twelve subsystem docs (`platform-reference/*.md`), one derivatives map (`platform-derivatives.md`), and one coherence audit (`platform-reference/coherence-audit.md`). Each subsystem doc is a capability catalogue tagged by the core each capability `reducesTo` (`fact` / `projection` / `cell` / `edge-http`).
